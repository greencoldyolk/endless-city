# LoRA 世代会考方法论（v1 会考实录 + 给 Codex 的研究题）

> 2026-07-17 定稿。每一代风格 LoRA 出炉后按此考。考卷图库：
> `assets/concepts/world-bg-v2/eval/v1/`。语料与 caption 见 corpus-candidates/。

## 1. 设计原则

- **同题、同 seed、同采样器**（euler/simple/24 步/guidance 3.5/权重 0.85）：
  代际差异全部归因于权重本身，不给抽卡方差留借口
- **公平题 vs 验收题分栏记分**：两代语料覆盖相同的题测"退步"；
  新语料独有的题（如 v1 的机场）v0 只当基线对照组，不计胜负
- **金丝雀卷**：选一道最易崩的题（当前=B 茶杯：载具+摊亭，天然诱发
  人物与乱码）做过拟合探针；关键判决用 **3 个 seed** 统计，不单样本定案
- **训练中样张只当体检报告**（粗采样器，画质七折看趋势）；
  终审一律 ComfyUI 正装渲染

## 3. 选档规律（两代实证）

- 影响力阈值：约 300–450 步 LoRA 接管画面
- 甜区：约 600–900 步（v0-e6=864 步、v1-e9=675 步）
- 侵蚀信号（超过甜区）：金丝雀卷人物/乱码增多 → 样张冒红字 → 构图复读
- 出图端权重可赎回服从：语料内 0.85 / 语料外或指令敏感 0.7

## 4. caption ↔ 出图 因果实录（给 Codex 的核心素材）

已确认的因果链，全部有考卷图为证：

1. **点名=开关**："closed-eyed woman" 进 caption → C 卷召之即来、
   D 卷挥之即去。点名的概念变成可控参数 ✓
2. **意外绑定**："artwork screens" 与她在 caption 中高频共现 →
   G 卷所有巨屏自动填充（睁眼变体）美女脸——**词共现即绑定**，
   稀有概念（她）不能和常用词（screen）同句高频出现
3. **正面措辞胜否定**：caption 里的 "empty/deserted" 学得进；
   prompt 里的 "no people" 底模基本无视
4. **点名=保险**：vending machine 被点名 → 不写就不出现（配额律成立）
5. **无字语料≠无字输出**：乱码是底模先验，caption 管不到，
   只能 prompt 压制＋后期
6. **红色清洗有效但有边界**：语料内学来的红（航标灯）断根；
   语料外场景（C 卷街景）素模先验的红仍会冒

## 5. 给 Codex 的研究题

对照 `corpus-candidates/` 的 25 条 caption 与 `eval/v1/` 的考卷输出，复盘：

1. 还有哪些**意外绑定**的苗头（某词一出、某物必现）？
2. 哪些世界概念**欠点名**（模型该会而不会、或不受控）？
3. v2 caption 修订提案：如何既保留她的开关、又拆掉
   "screen→美女"的绑定？（候选思路：给纯图案屏幕也写进 caption、
   给她的出现加更独特的限定词）
4. 机场组 D06/D07 用了 romantic purple twilight——从 E 卷输出看，
   色调标签跨组混用的利弊？
