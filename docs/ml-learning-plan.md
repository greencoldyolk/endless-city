# 调模型专业知识补课计划（实战反推理论版）

> 2026-07-18 立案。目标：能独立完成"调模型的活"——数据设计、caption 工程、
> 训练配置与除错、评测选档、控制技术，并有足够理论底子读懂社区讨论和论文。
> 原则：**一轮一旋钮同样适用于学习**；作业全部取自游戏的真实任务队列；
> 每阶段产出物入 repo；不设死线，跟着项目节奏走（估时按每天 1–2 小时算）。

## 阶段 0：地图与词汇（约 1 周）

把这几天已经做过的事系统化命名——你缺的是词，不是判断。

- **学**：生成图像技术全景图——底模 / LoRA / ControlNet / IPAdapter /
  inpaint / outpaint 各自站在管线哪一层、解决什么问题
- **读**（课本就是你自己的案卷）：`world-bg-v2-corpus-plan.md`、
  `world-bg-eval-method.md`、两份 LoRA 配方档案——这次以"理解每个词"
  为目标重读
- **作业**：写一页《给三个月前的自己》——用自己的话讲清 v0→v1 全过程
- **毕业标准**：不看文档，能对人说清"为什么定 e9 不定 e10"

## 阶段 1：ComfyUI 亲手驾驶（约 2 周）

目前所有出图都是我在 API 层替你开的车，方向盘该交给你了。

- **学**：节点图思维——任何工作流都是四段：模型加载 → 文本条件 →
  采样 → 解码；采样器/调度器/步数/guidance 每个旋钮拧一遍看差异
- **作业 ①**：**亲手搭出会考用的那个工作流**（不许导入我的 json，
  搭完对答案）；同题跑权重梯度 0.5→1.0 感受风格浓度曲线
- **作业 ②**：**inpaint 队列七单欠账亲手清**（角标、站牌、单轨花体字、
  红点残余）——这本来就是排队的生产任务
- **毕业标准**：独立完成一单 inpaint ＋ 一张分层出图（纯天空/远景剪影）

## 阶段 2：数据与训练学（约 3 周，核心）

- **学**：kohya 每个参数从"抄表"升级为"理解"——lr 与调度、dim/alpha、
  repeats×epochs÷batch 的步数账、bucket、bf16/fp8、梯度检查点、
  优化器；caption 工程（词共现绑定、点名=开关、正面措辞——这三条
  是你们自己的原创判例，社区教程里都没有）
- **读**：LoRA 论文（arXiv:2106.09685，最短最独立）；
  Rectified Flow 的引言和插图（arXiv:2209.03003）
- **作业 ①**：亲手设计并执行 v2 货架上的一个小实验炉——推荐
  **pworldwoman 正交实验**（小语料、单变量、便宜，完美的教学炉）
- **作业 ②**：**故意炼一炉过拟合**，写它的病历（症状时间线：
  构图复读→乱码→红字）——见过全程死亡的人才会判活
- **毕业标准**：不查笔记独立完成一整炉：配比→caption→参数→监工→
  选档→归档

## 阶段 3：控制技术（约 3 周）＝角色管线本身

这一阶段的课程作业就是游戏 P1 任务，学完游戏就有跑步动画。

- **学**：ControlNet 家族（OpenPose 骨架 / depth / canny 线稿）、
  IPAdapter（参考图注入）、多控制叠加与权重平衡
- **作业**（照 production-plan P1 清单）：主角定妆三视图 →
  IPAdapter 锁脸 → OpenPose 骨架序列出跑步 8 帧 → 筛选清理
- **毕业标准**：8 帧跑步，缩到指甲盖大小仍是同一个人

## 阶段 4：理论纵深（长期，按兴趣取用)

- **读**（按此顺序，前两篇之后随缘）：LoRA → Rectified Flow →
  DDIM 引言 → SD3（arXiv:2403.03206，Flux 的真身）→
  DDPM/Score-SDE（想深潜数学再碰）
- **数学诚实清单**——真正需要的只有三样：向量与矩阵乘法的直觉、
  梯度下降的直觉（"往哪边挪一小步"）、概率分布的常识。
  **不需要**推导 ELBO，不需要重修微积分
- **终极作业**：给"游戏完成后的慢速复盘"写讲义——你当讲师，
  我当助教（费曼学习法：讲得出来才是真会）
