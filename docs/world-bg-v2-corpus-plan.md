# project-world-bg 语料计划 v0（两条线共用宪法）

> 裁决日期：2026-07-17。来源：用户 × GPT 七问讨论定稿，Claude 落档。
> 适用范围：Codex 线（语料分析/清洗/训练）与 ChatGPT 生图线（抽卡）共同遵守。
> 背景：v1 风格 LoRA（emptycity style，36 张）审美否决，全部重做。

## 0. 目标与铁律

- 训练目标：`project_world_bg_style` —— **同一个世界的环境背景语言**，
  不是某一个地图组的画风。触发词沿用 `pworldbg`。
- **入炉三无**：无 UI、无文字、无人物。带人/带 UI 的 hero 只做参考图。
- **语料哲学**：风格一致、空间不同；主题相关、构图有变化；
  小数据集防"记构图"，近重复二选一。
- 纪律：每张过五维评分（favorite / illustration / playable_space / mood /
  project_fit，0–2 分），8+ 为 hero；hero 不足量不开正炉。
- 会话是耗材：生图新会话只带短版风格说明 + 3 张锚图 + 当次分镜。

## 1. 一炉还是两炉：先一炉

- v0 只练一炉"世界背景语言"。冷蓝城市与紫粉游乐园是**两个章节，
  不是两个画风**。
- **配比：城市 45% / 游乐园 45% / 过渡与母版 10%**。
  防两个失败模式：游乐园过多 → 风格被误解成紫粉童话；
  城市过多 → 退回冷蓝写实。
- caption 强制写清地图组与色调：`city_edge` / `amusement_park`、
  `cool rainy blue hour` / `romantic purple twilight`。
- 子 LoRA（`world_bg_city_edge` / `world_bg_amusement_park`）等两组都
  稳定后再分，现在数据太薄，分太早。

## 3. 插画感的落点

往游乐园的"华丽插画感"收，保留城市组的克制与真实空间：

- 可以有：真实透视、真实材质逻辑、真实建筑尺度
- 不可以像：照片、3D 渲染、写实 matte painting
- 表面细节被概括、灯光被诗意化、空间被设计过
- 城市不能只是雾里楼群，必须有"玩家能站、跑、停"的结构
- 不是"城市写实+游乐园梦幻"的平均值：**城市也要画成背景插画，
  游乐园也不能甜到脱离可玩空间**

## 4. 下一轮：车站/城市边缘 8 张分镜（全部无人纯环境，16:9）

1. **高架候车亭正侧面**：冷蓝雨后，暖灯候车亭，远景最高塔+斜拉桥；
   主路线前景站台平跑
2. **售货机小平台**：近景售货机+栏杆，中景轨道，远景临水岸线；
   窄平台+一个低台阶
3. **站台顶棚下方**：略低视角，顶棚压出安全感，少量垂藤；
   顶棚下横向通过，可抓边上顶棚短分枝
4. **铁轨旁维护步道**：前景湿轨道，中景维护道，远景城市几乎不动；
   偏工业但干净，不要废土
5. **玻璃连廊接车站**：城市内部过渡图，玻璃反射、广告背面，
   最高塔隐约可见；室内连廊向右
6. **临水站台外缘**：斜拉桥+水面反射为主地标，站台在岸线边；
   路线平缓，重点是巨大城市尺度
7. **高处屋顶站牌/小站口**：略俯视，建筑边缘小站口，下方是城市层级；
   可短跳上广告牌或屋顶边
8. **黄昏转初夜母版**：同样车站语言，色温稍紫、暖灯更明显——
   城市组与游乐园组之间的桥（计入 10% 过渡配额）

紫粉浓度在车站降到 20–30%：主色仍是冷湿蓝灰，
粉紫只给天空边缘和远处反光，不让车站变成游乐园。

## 5. 地标定案（转正）

- **城市正典**：最高塔 + 斜拉桥 + 临水岸线（以 A1 定稿为准，方位自洽）
- **次级地标**：高架轨道/空中连廊网络——比单个建筑更适合游戏，
  天然解释"为什么玩家能一直向右走"
- **跨地图输出**：摩天轮 = 游乐园输出给其他地图组的远程剪影
- **巨幅海报地标（2026-07-17 定案，同日修订为三层制）**：城市级地标，
  Hollywood 招牌尺度但**是画不是字**——正典画作 = 闭眼侧脸的无名女性 +
  金缮裂纹 + 星月木马灯饰纹样（与游乐园大门拱同一纹样家族，
  四格选角板胜出）。她是谁：永不解释。
  **三层使用制**（否决"满城同一张脸"——那读作品牌宇宙/控制社会）：
  ① 正典全幅人像仅 2–4 个重要位置（城市核心巨幅、商场中庭旧灯箱、
  机场/车站大墙面艺术），可走到正面/背面/顶部，作关卡记忆点；
  首个圣地定案（2026-07-17）：**空无一人的时代广场式街心**——
  巨屏正典人像+周边小屏纯纹样（第②层），湿街倒影；
  这里就是"入城后第一次正面遭遇她"的仪式点位（第一关仅天际线远望）；
  概念 hero 已出（信号灯青色、无字、无人版）；
  ② 纹样家族扩散：金缮、星月木马、深蓝灰紫柔金、花朵圆形细线——
  部分广告只出现局部（手、肩、发丝剪影、闭眼轮廓）或纯纹样；
  ③ 其余海报完全不同（抽象图形、商品活动、风景动物、褪色灯箱、
  几何色块）——她因稀有而特殊。
  **密度律**：一个五分钟关卡最多一次完整大幅人像，其余只用局部纹样
  或远景剪影呼应；第一关只可远远看见，入城后才第一次正面遭遇（仪式感）。
  待产资产：画作本体贴图（正视无透视无边框），凡出现正典人像处
  一律由本体贴图投影/重绘，防脸漂
- 地标不增殖：一座摩天轮、一个湖、一个主木马、一幅正典巨幅海报

## 6. 游乐园正典鸟瞰（母版）

- 不选现有某张（14/15/16 是情绪图不是路线图），**综合重画一张标准母版**
- 路线顺序定案：**入口（偏低处）→ 木马广场（第一大亮点）→
  湖岸（呼吸）→ 过山车维护层上轨（路线抬高）→ 轨道段 →
  摩天轮（终点剪影与情绪收束）**
- 配套已定案（game-design §25.9）：园区不命名——招牌**图案化**不做剥落
  （灯饰拱排星月/木马图案、票亭灯箱为发光车票图形，灯亮、被照顾感；
  剥落态仅限重废墟区段）、大门=气闸（预告立面+前景切面剪影两张资产）、
  禁恐怖片语汇
