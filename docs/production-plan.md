# Empty City Runner 资产生产计划

> 原则（2026-07-13 踩坑总结）：**先小样、后管线；先清单、后生成；先存档、后换资产。**
> 工具按任务选，GPT 不行就换，不跟单一工具较劲。

## 0. 铁律

1. **动任何已上线资产前先 git 提交**（未提交的手工标定丢了找不回来）
2. **大改先出小样对比**：一屏内新旧并排，看过再走管线（母图换风格的教训）
3. 每类资产生成前先写好**验收清单**，拿图逐条打勾，不满足就重来，不凑合接入
4. 氛围 > 风格统一：细节是氛围的载体，"干净"永远不能以牺牲 feeling 为代价

## 核心概念（2026-07-13 定稿，多解释性是设计原则）

> 一座空城，机器照常运转：售货机亮着，电台播着，路灯为无人的街道亮起。城里只有一个奔跑的少年。这是怎么回事——游戏永远不说。它可以是字面意思的世界，可以是一场很长的梦，也可以是一个人内心的形状。每个玩家带走自己的解释，游戏只负责那种感受本身：一个人站在宏大而安静的世界面前——孤独，但不压抑。

- **永不解释**：不放任何"线索型"物件（日历/报纸），连问题都不提出
- **比例即情绪**：天要高、天际线要远、人要小（崇高感的工程化）
- **机器是环境的呼吸**，不是玩法公式；无人列车先做远景驶过事件
- **温暖闭环**：撞击失去温暖，机器补给温暖

## 2.5 "不出戏"三要素与双 LoRA 架构

出戏（贴纸感/劣质感）= 三个不一致，各有对应解法：

1. **接触影**：障碍物→影子直接烘进素材（永不移动，无破绽）；角色→贴地帧烘焙影+空中代码影
2. **环境色**：角色/道具在 SD 生成时就带场景光（蓝紫暮色环境色+暖灯侧光），不再事后代码调色
3. **笔触/细节密度**：靠风格 LoRA 统一

**双 LoRA 架构**：
- **角色 LoRA**（他是谁）：训练集=定妆照+动画帧+站姿图
- **风格 LoRA**（世界长什么样）：训练集=现母图切块+历史概念图
- 所有新资产 = 角色/物件条件 + 风格 LoRA + OpenPose 姿势控制；母图为风格圣经不重画，仅低强度提质与 inpaint 修缮
