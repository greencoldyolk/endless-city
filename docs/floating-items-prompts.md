# 《空城跑酷》三类悬浮物 AI 生图 Prompt

> 用途：生成可直接抠图、缩小后接入 2D 横版游戏的独立小物件素材。  
> 建议三种物件分别生成，不要一次画在同一张图里，以便保证尺寸、轮廓与透明度可控。

---

## 0. 统一美术基线

所有素材必须遵守以下规则：

- 背景为纯品红色 `#FF00FF`
- 背景必须纯色平涂，不要渐变、纹理、噪点或暗角
- 图中只保留目标物件本体
- 不要地面、投影、外部反射、环境、人物、文字、边框或色板
- 物件居中并尽量占满画面，但必须完整显示，不可切边
- 风格为低饱和、柔和平涂、轻微动漫感的 2D 游戏小物件
- 非写实，不要摄影质感，不要塑料 3D 渲染感
- 轮廓清楚，缩小后仍能辨认
- 细节适中，避免密集纹理和过多高光
- 整体属于“雨后黄昏的空城”：安静、孤独、温柔，带少量残存暖意
- 不要做成金币、宝石、抽卡道具或霓虹奖励物

### 通用排除项

```text
不要写实摄影，不要 3D 渲染，不要高饱和，不要霓虹色，不要金币感，
不要大型光晕，不要强烈发光，不要投影，不要地面，不要环境背景，
不要人物或手，不要文字、Logo、序号、边框、标签、色板，
不要物件被裁切，不要复杂装饰，不要过密细节，不要强金属反光。
```

# 1. 暖黄色气泡

## 1A. 仅生成气泡外壳

适合后续在程序中把咖啡罐或其他小物件放进气泡内部。

```text
为一款 2D 横版游戏绘制一个独立的暖黄色漂浮气泡素材。

背景必须是纯品红色 #FF00FF，纯色平涂，不要渐变、纹理、暗角。
图中只要一个气泡本体，不要地面、投影、人物、文字、边框或其他物件。

气泡接近圆形，但不要是机械般完美的正圆，轮廓略微柔软、不规则，
像一团被温暖空气托住的透明薄膜。整体为低饱和的蜂蜜琥珀黄，
让人联想到冬日里手握暖饮的治愈感，但不要画冬天、雪、手或场景。

推荐配色：
主体 #DDB65A
内部浅色 #E8CC83
较暗边缘 #A87938
极小高光 #F3E0AC

气泡带轻微半透明感和柔和内部明暗，
仅在左上方保留一小块奶油黄色高光。
不要大范围光晕，不要强烈发光，不要玻璃球般锐利反光，
不要做成肥皂泡、宝石、金币或科幻护盾。

风格为低饱和、柔和平涂、轻微动漫感的 2D 游戏素材，
安静、温柔、非写实。气泡居中并尽量占满画面，同时完整显示。
```

## 1B. 完整成品：咖啡罐包裹在暖黄色气泡内

适合直接作为游戏中的可收集悬浮物。

```text
为一款 2D 横版游戏绘制一个独立的悬浮收集物：
一罐棕色罐装咖啡，被包裹在一个暖黄色半透明气泡中。

背景必须是纯品红色 #FF00FF，纯色平涂，不要渐变、纹理或暗角。
图中只保留气泡和气泡内部的咖啡罐，不要地面、投影、人物、文字、
边框、额外道具或环境。

外层气泡接近圆形但略微柔软、不规则，
颜色为低饱和蜂蜜琥珀黄，柔和半透明。
气泡不要强烈发光，只保留轻微内部亮度、
一圈较暗的琥珀边缘，以及左上方很小的奶油黄高光。
不要大型光晕，不要霓虹，不要做成金币或科幻护盾。

内部是一罐简洁的棕色罐装咖啡：
罐身为低饱和深棕与暖棕色，设计朴素、安静、略带旧式自动售货机饮品感。
只保留少量简化装饰，例如很小的咖啡豆或植物纹样，
不要品牌文字，不要密集包装信息，不要写实金属反光。

气泡与咖啡罐共同传达：
雨后灰蓝空城中残留的一点暖意，
像冬日里拿着暖咖啡的治愈感，但不要把冬天或环境画出来。

风格为低饱和、柔和平涂、轻微动漫感的 2D 游戏小物件，
轮廓清楚，缩小后仍能辨认。整体居中、尽量大、完整显示。
```

# 2. 旧便携收音机

## 推荐最终 Prompt

```text
为一款 2D 横版游戏绘制一个独立漂浮的旧便携收音机素材。

背景必须是纯品红色 #FF00FF，纯色平涂，不要渐变、纹理、噪点或暗角。
图中只保留收音机本体，不要地面、投影、人物、文字、边框或环境。

收音机是小型旧式便携款，横向长方形，轮廓清楚，
带一根简化的短天线、一块横向频段窗、一块较大的喇叭网格、
两个大小不同的旋钮，以及一根很短的旧腕带。
结构要足够让人一眼认出是收音机，但不要堆叠很多按钮和刻度。

配色低饱和：
主体深灰棕 #6B5B4D
次色旧棕 #8B7763
浅面旧米色 #A99782
旋钮与小金属件 #8D744D

它看起来被保存了很多年，但不是废品：
可以有极少量边缘磨损和旧漆感，
不要严重破损、锈蚀、开裂或沾满污垢。

收音机本体不主动发光，
最多让频段窗里有一个非常小、非常弱的暖色指示点。
不要外部光晕，不要投影，不要强金属反光。

不要在静态素材里画明显的音乐符号。
音乐、电流和消散在风中的旋律应当作为游戏运行时特效单独实现。

风格为低饱和、柔和平涂、轻微动漫感的 2D 游戏小物件，
安静、怀旧、略有重量感，适合漂浮在雨后黄昏的空城中。
收音机居中并尽量占满画面，同时完整显示，不可切边。
```

## 可选：音乐触发特效单独素材

```text
绘制一组极淡的音乐消散特效素材，用于旧收音机播放短暂旋律时叠加。

背景纯品红色 #FF00FF。
只画几缕非常轻、非常细的暖灰黄色弧线和极少量抽象音波碎片，
像声音刚刚出现便被风吹散。
不要画清晰卡通音乐符号，不要霓虹，不要强光，
不要烟雾团，不要大面积粒子。
整体稀疏、短暂、安静，适合作为 2D 游戏中的淡入淡出特效。
```

# 3. 透明旧雨伞

## 推荐最终 Prompt

```text
为一款 2D 横版游戏绘制一把独立漂浮的透明旧雨伞素材。

背景必须是纯品红色 #FF00FF，纯色平涂，不要渐变、纹理、噪点或暗角。
图中只保留雨伞本体，不要地面、投影、人物、文字、边框或环境。

雨伞为透明圆顶长柄伞，伞面展开，
从略偏侧面的角度观察，让伞面、伞骨和弯柄都能清楚辨认。
整体轮廓轻盈，像水母一样适合缓慢漂浮。

伞面是低饱和的透明灰蓝色，
主体参考 #AEB8C4
伞骨与边缘参考 #7F8893
少量高光参考 #D8E0E8

透明度要自然，但不要完全透明到看不见。
伞骨数量适当简化，不要过密。
边缘可以有很轻微的旧痕和略微卷曲，
伞面上只保留少量残余水珠，其中两三颗悬在边缘，
不要画雨景、落雨或水花。

雨伞不主动发光，
主要依靠灰蓝透明面、边缘轮廓和少量柔和高光保持可读性。
不要大型光晕，不要投影，不要婚礼装饰感，
不要少女梦幻风，不要鲜艳紫色或亮蓝色。

风格为低饱和、柔和平涂、轻微动漫感的 2D 游戏小物件，
安静、诗意、略旧，但不破烂。
雨伞居中并尽量占满画面，同时完整显示，不可切边。
```

# 4. 三种物件的一致性检查

生成完成后逐项检查：

- [ ] 三张图的背景都是真正的纯色 `#FF00FF`
- [ ] 没有地面、投影、人物、文字、边框或场景
- [ ] 三种物件都完整显示，没有切边
- [ ] 都是低饱和、柔和平涂，而不是写实或 3D 渲染
- [ ] 暖气泡是唯一明显的暖黄色主体
- [ ] 收音机比气泡更有重量感，但没有外发光
- [ ] 雨伞最轻、最透明，伞骨没有过密
- [ ] 缩小后仍能一眼分辨三种轮廓
- [ ] 没有任何一种看起来像金币、抽卡道具或霓虹奖励物
- [ ] 三种物件放进同一场景时，明暗和细节密度一致

# 5. 游戏内建议尺寸关系

以角色身高为 `1.0`：

| 物件 | 推荐可视尺寸 |
|---|---:|
| 暖黄色气泡 | 角色头部的 `0.45–0.70` |
| 气泡内咖啡罐 | 占气泡直径的 `45%–60%` |
| 旧收音机 | 角色头部的 `0.80–1.05` |
| 透明旧雨伞 | 展开宽度为角色身高的 `0.65–0.85` |

建议导入游戏前保留一份高分辨率源图，再分别缩放，不要直接以最终显示尺寸生成。

# 6. 动态表现简表

| 物件 | 上下浮动 | 左右摆动 | 旋转 | 触发反馈 |
|---|---|---|---|---|
| 暖黄色气泡 | 稍明显 | 很轻 | 几乎无 | 柔和“啵”声，轻微收缩后消失 |
| 旧收音机 | 较小 | 很轻 | 缓慢倾斜回正 | 播放 `2–5s` 音乐碎片，逐渐被风声吞没 |
| 透明旧雨伞 | 缓慢 | 可被风推偏 | 轻微自转 | 淡出、水滴声或伞骨轻响 |

同屏建议只出现 `1–3` 个悬浮物，避免破坏空城的寂静感。
